BEFORE FIXES (original hand-written numbers, kept for comparison)
======================================================================
These are NOT comparable to the numbers above:
- Fly count: the label was min(#contours, 2) and the features were the
  sizes of those same contours, so 100% was guaranteed by construction.
- Orientation: features were distances/angles between the annotated
  head/body/abdomen keypoints, and the label came from the same points;
  at inference the pipeline fed the model placeholder constants.
- Wing angle: keypoint features included the sin/cos of the annotated
  wing direction; random split put the two wings of one image on both
  sides; inference used placeholder constants.
- Sex: same features as now, but one 52-sample test split (noisy).
- All: a single 80/20 split; orientation and wing were not grouped.
