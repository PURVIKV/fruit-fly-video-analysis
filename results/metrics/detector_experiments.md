Generated by `python eval_detectors.py`. Each candidate changes one detector switch (see `src/detection.py`). For every candidate the count tree is retrained on the annotated images with that detector, then run on all test videos (correct count = 2 in every frame), and all four tasks are scored with leave-one-session-out (LOSO) cross-validation. Dataset sizes change because the detector decides which flies are found as separate contours.
